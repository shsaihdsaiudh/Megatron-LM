# What does this PR do?

Pipeline HFSDP parameter gathers: DP-Outer gathers are prefetched one more unit ahead to speed up subsequent DP-Inner gathers.

This PR is better reviewed commit-by-commit. First commit refactors some common code to prepare the additional functionality. The second commit adds the pipeline functionality. The third commit adds relevant flags to all necessary places.

I've run some small-scale experiments locally, with Llama 3 8b for 50 iterations, and seen a measurable speedup of ~5%. However, for fused fp8 attentions, I also noticed some increase in loss dispersion (none in deterministic mode).
