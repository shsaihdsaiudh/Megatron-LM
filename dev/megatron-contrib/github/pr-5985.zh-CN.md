# 这个 PR 做了什么？

流水化 HFSDP 参数 gather：把 DP-Outer gather 再提前一个 unit 预取，以加速后续的
DP-Inner gather。

这个 PR 最好按提交逐个评审。第一个提交重构了一些公共代码，为新增功能做准备。第二个
提交加入流水线功能。第三个提交把相关开关加到所有必要的位置。

我在本地用 Llama 3 8b 跑了 50 次迭代的小规模实验，观察到约 5% 的可测量加速。不过对于
融合的 fp8 attention，我也注意到 loss 离散度有所增加（确定性模式下没有）。
