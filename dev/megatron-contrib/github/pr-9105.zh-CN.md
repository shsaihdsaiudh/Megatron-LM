# 这个 PR 做了什么？
启用 `hfsdp_param_gather_overlap` 时，一个比剩余预取尺寸更大的 DP-Outer bucket 可能
在下一个 FSDP unit 中途结束 DP-Inner 预取窗口。该 unit 剩余的部分只能在它自己的
pre-forward hook 中 gather，落在关键路径上。现在窗口会把它所结束的那个 FSDP unit 走完，
最多因此多出一个 unit 的尺寸，且绝不会继续往后走。
